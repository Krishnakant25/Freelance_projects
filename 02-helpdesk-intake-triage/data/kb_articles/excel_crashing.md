# Excel crashing or freezing on large files

If Excel crashes or freezes when opening large spreadsheets: 1) Disable hardware graphics acceleration — File > Options > Advanced > Display > check "Disable hardware graphics acceleration". 2) Check for and disable unnecessary add-ins — File > Options > Add-ins > Manage: COM Add-ins > Go, uncheck anything you don't actively use. 3) Make sure Excel is fully updated — File > Account > Update Options > Update Now. 4) If the file has heavy formulas or many conditional formatting rules, try opening it in Excel Online instead, which handles large files differently. 5) Restart your computer — a stuck background process is a common cause. If it still crashes on this specific file after these steps, submit a ticket and attach the file if possible.
